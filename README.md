# Play TV

Player de IPTV (PWA) para canais ao vivo, filmes e séries a partir das playlists do próprio usuário: login Xtream, link M3U, arquivo .m3u ou link de um canal.

O app **não fornece conteúdo**: apenas reproduz listas que o usuário tem direito de assistir.

## Recursos
- Tela inicial em vitrine (destaque rotativo + fileiras por categoria)
- TV ao vivo com categorias, favoritos e troca de canal
- Filmes e séries (temporadas e episódios, sinopse, trailer via Xtream)
- Continuar assistindo, Assistir depois, perfis e controle parental com PIN
- Instalável (PWA) e navegável por controle remoto (Smart TV / TV Box)

## Publicar
Site estático, sem build. Na Vercel: importar o repositório → Framework "Other" → Deploy.
